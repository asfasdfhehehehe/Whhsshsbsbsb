INSTALLATION GUIDE
========================================

For Termux/Arch Linux:

1. Navigate to repository:
   cd /app/Solana-Trading-Bot

2. Run automated setup:
   ./setup_termux.sh

3. Start MongoDB (if not running):
   mongod --dbpath ~/data/db &

4. Start all services:
   ./start_bot.sh

5. Access dashboard:
   http://localhost:3000

6. Stop services when done:
   ./stop_bot.sh
